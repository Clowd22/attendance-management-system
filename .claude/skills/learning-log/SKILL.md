# 学習ノートの記録規約

このプロジェクトはWeb開発の学習を主目的とする。質問と回答（特に例えを使った概念解説）は、あとで見返せるように `docs/学習ノート/` に蓄積する。

- 設計書（`docs/01_〜03_`）＝ **作るものの仕様**
- 学習ノート（`docs/学習ノート/`）＝ **学んだこと・理解の記録**

## 置き場所と命名

- フォルダ: `docs/学習ノート/`
- ファイル命名: `NN_トピック名.md`（`NN` は2桁連番。`00_このフォルダについて.md` が目次兼ガイド）
- 質問1件 = ファイル1つ

## テンプレート

```markdown
# トピック名

| 項目 | 内容 |
|------|------|
| 作成日 | YYYY-MM-DD |
| 種別 | 概念理解 / 手順 / エラー解決 など |

## 質問

> ユーザーがした質問をそのまま書く（表現を変えない）。

## 回答の要旨（結論）

結論を先に一言で。

## 例え / ポイント

初学者向けに例えがあれば簡潔に。コード上の要素とその役割は表で整理する。

## 関連ファイル・次のステップ

- 実装ファイルや設計書への参照
