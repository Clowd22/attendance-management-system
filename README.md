# 勤怠管理システム（Attendance Management System）

社員の出退勤管理・勤怠集計を行う Web アプリケーションです。

> ⚠️ **重要**: このリポジトリは **パブリック** です。
> 実在の勤怠データ・人事データ・秘密情報（パスワード等）は絶対にコミットしないでください。
> 動作確認にはダミーデータ（シードデータ）を使用します。

## 技術スタック

| 分類 | 技術 |
|------|------|
| 言語 | Python 3.13 |
| Web フレームワーク | FastAPI |
| 画面 | サーバーサイドテンプレート（Jinja2） |
| データベース | SQLite（SQLAlchemy ORM + Alembic マイグレーション） |
| 認証 | 社員ID + パスワード（bcrypt ハッシュ化・セッション管理） |

> このプロジェクトは「Web アプリケーション開発を通しての学習」を主目的としています。
> コードには細かなコメントを、`docs/` には実務レベルの設計ドキュメントを整備しています。

## セットアップ手順

```bash
# 1. 仮想環境の作成
python3 -m venv .venv

# 2. 依存パッケージのインストール
.venv/bin/pip install -r requirements.txt

# 3. 環境変数の準備
cp .env.example .env   # 必要に応じて値を編集
```
