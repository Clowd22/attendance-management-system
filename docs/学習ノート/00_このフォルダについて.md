# このフォルダについて（学習ノート）

ここは「設計書の仕様を実装しながら、学んだこと・理解したことを**質問と回答の形**で蓄積する」ための場所。

- 設計書（`docs/01_〜03_`）＝ 作るものの仕様 
- 学習ノート（このフォルダ）＝ 学びの記録

## ファイル命名

- `NN_トピック名.md`（`NN` は2桁連番。`00` は本ガイド）
- 質問1件 = ファイル1つ
