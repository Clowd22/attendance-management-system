## 質問

> 実装できた。ついでにステップ１３まで進めた。なぜならでもデータがないとテストしにくいので。これもテストケースを立てて実行して、学習ノートに記載してコミットpUSHまでして。

## 回答の要旨（結論）

`main.py`（アプリ本体）は `TestClient` でエラーハンドラ（404）や起動を検証する。`seed.py`（シードデータ）は `seed_all()` を実行して「期待どおりの件数」と「冪等性（何度実行しても同じ初期状態）」を検証する。

## main.py のテスト

`app.main` の `app` をそのまま使う。ステップ11 でテスト内に組み立てていたアプリを、本物の `app` に置き換えられる。

```python
from app.main import app
client = TestClient(app)
```

| ID | 分類 | 内容 | 期待結果 |
|----|------|------|----------|
| T-MAIN-01 | 異常系 | GET 存在しない URL | 404、「404 - ページが見つかりません」 |
| T-MAIN-02 | 正常系 | GET /login | 200、ログインフォーム |

ポイント：404 エラーハンドラ（`@app.exception_handler(404)`）が専用ページを返すことを検証する。

## seed.py のテスト

`seed_all()` を実行し、件数と冪等性を検証する。

```python
from sqlalchemy import func, select

def _count(model):
    db = SessionLocal()
    try:
        return db.scalar(select(func.count()).select_from(model))
    finally:
        db.close()
```

| ID | 分類 | 内容 | 期待結果 |
|----|------|------|----------|
| T-SEED-01 | 正常系 | seed_all() 実行後 | 社員6名 |
| T-SEED-02 | 正常系 | seed_all() 実行後 | 部署3件 |
| T-SEED-03 | 正常系 | seed_all() 実行後 | 勤務体系1件・休暇種別4件 |
| T-SEED-04 | 正常系 | seed_all() 実行後 | 管理者1名 |
| T-SEED-05 | 正常系 | 2回実行 | 冪等（社員6名のまま） |

ポイント：seed は「全件削除 → 再投入」の冪等な実装なので、2回実行しても件数が変わらないことを検証する。
