## サーバーログの読み方

`.venv/bin/uvicorn app.main:app --reload` で起動したときのログから、各リクエストがどう処理されたかが分かる。

| ログ | 意味 |
|------|------|
| `GET / → 303` → `GET /login → 200` | 未ログインでホームへ → ログイン画面へリダイレクト |
| `POST /login → 303` → `GET / → 200` | ログイン成功 → ホーム画面表示 |
| `POST /login → 401` | 誤パスワード → エラー |
| `GET /logout → 303` → `GET /login → 200` | ログアウト → ログイン画面へ戻る |
| `GET /nothing → 404` | 存在しない URL → 404 ページ |

`303 See Other` は「リダイレクト」、`401 Unauthorized` は「認証失敗」、`404 Not Found` は「ページ不存在」を表す。
